# Gerador de Documentos Administrativos

Site simples para geração de modelos de documentos administrativos.

## Objetivo

O objetivo do projeto é facilitar a criação de documentos formais, como ofícios, pareceres, justificativas e respostas administrativas.

## Funcionalidades atuais

- Página inicial do projeto
- Gerador de Ofício
- Botão para copiar o texto gerado
- Layout responsivo para celular, tablet e computador

## Funcionalidades planejadas

- Gerador de Parecer
- Gerador de Resposta Administrativa
- Modelos prontos de documentos
- Páginas otimizadas para mecanismos de busca
- Integração futura com inteligência artificial
