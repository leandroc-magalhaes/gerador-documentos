# Gerador de Documentos Administrativos

Projeto simples para geração de documentos administrativos e institucionais.

## Funcionalidades

- Gerador de Ofícios
- Modelos administrativos
- Ferramentas para documentos formais

## Objetivo

Facilitar a criação de documentos administrativos utilizando automação e inteligência artificial.
